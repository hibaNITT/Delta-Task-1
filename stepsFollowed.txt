21. power up - row ripper-
The Row Ripper code is split into four parts:

In state_manager.js, the game keeps a rowRipperCurrentRow value in state. That is the row the power-up is currently on.
 It starts at 0 and changes as the icon moves down the board.

In eventhandler.js, initRowRipperIndicator() moves the icon downward over time.
 It finds the real screen position of the current row and places the icon there. 

 When a cell explodes, explodeCell() calls activateRowRipper(row, currentPlayer). T
 hat function checks whether the explosion row matches the current Row Ripper row. 
 If it matches, it applies your rule to every cell in that row:

empty cell gets 1 piece from the current player

current player’s cell gains 1 piece

opponent’s cell is cleared and replaced with 1 piece owned by the current player

It then shows the effect and banner through showRowRipperEffect()
 and showTransitionEffect("ROW RIPPER"), and plays the teleport sound.

In styles.css, the power-up has its visual treatment:
 the row flash, glow, and the moving icon styling outside the board.

In index.html, the indicator element itself is placed
 beside the board so it can move independently.
